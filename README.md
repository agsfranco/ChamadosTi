# ChamadosTI
**Sistema de gerenciamento de Help Desk para profissionais de TI**
* Sistema desenvolvido em Asp.Net Core 10.0 utlizando arquitetura MVC, sem o uso de IA genetativa.

**Tecnologias/Ferramentas utilizadas**
1. Entity Framework
1. Identity
1. Libman
1. FluentAPI
1. Bootstrap
1. Jquery
1. Jquery-validation-unobtrusive

* Observações: 
1. Os valores DateTime estão sendo gravadas no banco em UTC
